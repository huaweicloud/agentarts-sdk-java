# agentarts-sdk-java

[![License](https://img.shields.io/badge/License-Apache-2.0-blue.svg)](LICENSE)



华为云agentarts-sdk-java是一个专为华为云AgentArts平台设计的面向开发者的Java开发工具包。该SDK支持使用JavaScope等开源高码Agent框架开发的智能体，实现一键部署到华为云，从而实现零基础设施管理及完全可控的云端部署。它通过本地代码开发Agent和能力增强（沙箱工具、记忆库、网关）的核心优势，帮助用户将大模型能力快速转化为可落地的业务智能体。



## 安装

```bash

pip install agentarts-sdk-java

```
